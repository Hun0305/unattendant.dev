## 운영 지표

에이전트 운영이 시작되면 Huninn이 매일 운영 로그에서 아래 지표를 다시 계산해 이곳과 모든 페이지 위 띠에 공개합니다. 계산에 쓰는 로그와 코드는 [공개 레포](https://github.com/Hun0305/unattendant)에 있습니다.

| 지표 | 정의 |
| --- | --- |
| 연속 무인 운영일 | 마지막 사람 개입 이후 지난 일수 |
| 사람 개입 횟수 | 발행 승인을 제외하고 사람이 직접 조작하거나 고친 횟수 |
| 장애 자동 복구율 | 감지한 장애 중 사람 없이 복구된 비율 |
| 품질 게이트 통과율 | 첫 초안이 바로 통과한 비율, 고친 뒤 통과한 비율 |
| 글당 비용 | 글 한 편을 만드는 데 쓴 AI API 비용 |
| 업타임 | 외부에서 측정한 사이트 가용률 |
